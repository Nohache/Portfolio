📜 Adoptez une architecture MVC en PHP

OpenClassrooms · 2025

Objectif : Structurer une application web PHP avec le pattern Modèle-Vue-Contrôleur.

Contenu : Séparation des responsabilités, routage, templating, interactions avec une base de données MySQL.

Projet final : Création d’un mini-blog avec espace d’administration.

Compétences visées : PHP orienté objet, PDO, architecture logicielle, sécurité de base.
