📋 Application de gestion de bibliothèque

📅 Janvier – Avril 2025 · Projet scolaire

Contexte : Le lycée souhaitait informatiser la gestion de sa bibliothèque interne. L'application devait permettre aux élèves de consulter le catalogue, de réserver des ouvrages et aux bibliothécaires de gérer les emprunts.

Réalisations :

  • Analyse des besoins et modélisation UML (diagrammes de cas d'utilisation, de classes).
  • Base de données MySQL avec 8 tables.
  • Back-end PHP procédural avec authentification.
  • Front-end responsive avec Bootstrap et JavaScript.
  • Back-office administrateur.

Compétences : PHP, MySQL, UML, Bootstrap, gestion de projet.

PHP MySQL HTML/CSS Bootstrap UML
