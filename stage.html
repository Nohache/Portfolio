🏢 Développeur Web – Stage de 2ᵉ année

📅 5 Janvier – 13 Février 2026 · Cholet Services, Cholet

Objectif :Je travaille sur la refonte d’un site wordpress, dans lequel certains problèmes esthétiques doivent être corrigés, et je dois ajouter des fonctionnalités liées à une connexion utilisateur ainsi qu'implémenter des fonctionnalités pour chaque type d’utilisateurs.

Principales réalisations :

  • Correction des pages du site liées à de mauvaises couleurs, typographie.
  • Développement d'une extension au site WordPress comprenant une connexion utilisateur.
  • Implantation d'iframe dans le site WordPress.
  • Ajout de tables dans la base de données.

Rendu extension site WordPress (Gestionnaire) :

  • Le site web à donc été fait sur WordPress, voici la page d'accueil du côté gestionnaire (à savoir CholetServices eux mêmes). Le tableau que l'on peut voir est un iframe que j'ai implenté sur le site. On peut y voir un système de CRUD (Create, Read, Update, Delete), mais aussi un système de filtrage avec les cases "Lu" et "Non lu", et avec la barre de recherche.
  • Voici la page Gestion des Clients du côté gestionnaire. Sur cette page on peut voir tous les clients qui ont été créé. Il existe un endroit ou l'on peut voir tous les salariés aussi, la page ressemble exactement à celle-ci. Si on appuie sur un client, un petit menu va s'afficher dans lequel on pourra choisir de "Voir le profil", "Assigner à un salarié" ou de "Fermer".
  • Voici l'endroit où ajouter de nouveaux clients. C'est donc sur cette page que l'on va mettre toutes les infos liés au compte du client. Il existe un endroit ou créer des salariés aussi, la page ressemble exactement à celle-ci.
  • Voici l'endroit ou le gestionnaire a accès au profil d'un client. Cette page ressemble ressemble exactement à la page de profil du client (voir plus bas), cependant le gestionnaire a un bouton modifier dans lequel il peut réécrire toutes les informations à sa guise, et pour modifier la partie "Tâches Habituelles", le gestionnaire a accès à ce tableau pour sélectionner plus rapidement les tâches. La possibilité de changer le profil existe aussi pour les salariés, cependant il n'y a que une seule cases du nom de "Informations Complémentaires".
  • Cette page va permettre d'assigner un client à un salarié. C'est à dire que l'on va choisir un client, puis choisir un salarié, et ensuite on va assigner le client au salarié. Cela permettra au salarié de suivre les demandes du client et de lui répondre plus facilement. A noter que le salarié ne peut voir que les clients qui lui ont été assigner.
  • Suite à la demande de notre maître de stage, j'ai créer une page de blog dans laquelle il pourra créer des blogs à mettre à la vue de tous le monde dans le site.

Rendu extension site WordPress (Client) :

  • Voici la page d'accueil du client. Sur cette page le client peut voir les notifications que les salariés peuvent lui envoyer, en appuyant sur le bouton "Voir", le client peut voir le message qui a été envoyé et savoir qui lui a envoyé le message. De plus, sur cette page, le client peut lui-même envoyer des messages à un salarié auquel il a été assigné. Le client dispose aussi d'un historique de ses messages envoyés.
  • Sur cette page, le client va pouvoir voir son profil qui a été préalablement créé par le gestionnaire. Le client n'a pas la possibilité de changer son profil à sa guise, s'il veut le faire il devra demander au gestionnaire, à savoir CholetService, de modifier son profil.
  • Sur cette page le client pourra communiquer avec CholetService directement, cela permet d'éviter d'envoyer directement un mail à l'entreprise. Le gestionnaire verra le message dans sa page d'accueil préalablement montrer plus haut.

Rendu extension site WordPress (Salarié) :

  • Voici la page d'accueil du salarié. Sur cette page le salarié peut voir les notifications que les clients peuvent lui envoyer, en appuyant sur le bouton "Voir", le salarié peut voir le message qui a été envoyé et savoir qui lui a envoyé le message. De plus, sur cette page, le salarié peut lui-même envoyer des messages à un client qu'on lui a assigné. Le salarié dispose aussi d'un historique de ses messages envoyés.
  • Sur cette page le salarié peut voir tous les clients qui lui ont été assigné par le gestionnaire, cela lui permet de voir le profil de ses clients et de connaître leur besoins. Si on appuie sur un client, un petit menu va s'afficher dans lequel on pourra choisir de "Voir le profil" ou de "Fermer".

Outils : PHP, WordPress, Git, PHPMyAdmin.

💻 Développeur WEB – Stage de 1ʳᵉ année

📅 16 Mai – 25 Juin 2025 · Familles Rurales, Bressuire

Objectif : Informatiser l'entreprise.

Principales réalisations :

  • Changement du site web de l'entreprise.
  • Création d'un livret d'accueil pour les nouveaux employés.
  • Assistance à l'entreprise dans l'utilisation des outils informatiques.
  • Mise en place de QRCode

Languages : HTML, CSS, JavaScript, Python.

Rendu changement site web:

  • Le site web à été fait sur WordPress, on m'a demandé de refaire certaines pages. Cette page a été totalement refaite par mes soins et d'après les avis de l'entreprise. Certaines pages ont été refaite mais qu'avec des changement mineures comme de la mise en forme, des liens qui ne mène nul part, ...

Rendu livret d'accueil:

  • Voici la page d'accueil du livret d'accueil que j'ai créé pour les nouveaux employés de l'entreprise. J'ai choisi un thème qui correspond à l'identité visuelle de l'entreprise.
  • Voici un exemple de page que l'on peut retrouver dans le livret d'accueil. Sur cette page j'ai rajouté un système d'effet parallaxe : c'est à dire que les éléments de l'arrière-plans se déplacent plus lentement que les éléments au premier plan lors du défilement de la page
  • Voici un exemple de menu. Ce sont des pages qui sont là pour segmenter le livret d'accueil en différentes parties.
  • Voici le code d'un élément que j'ai utilisé dans le livret d'accueil, c'est un loader. Un loader est une animation qui s'affiche pendant le chargement d'une page ou d'un élément. J'ai utilisé ce loader pour rendre l'expérience utilisateur plus agréable pendant le chargement du livret d'accueil.

Rendu QRCode:

  • Voici le code d'un QRCode que j'ai créé pour l'entreprise. Un QRCode est un code barre en 2D qui peut être scanné avec un smartphone pour accéder à une page web ou à une information. J'ai créé ce QRCode pour permettre aux employés d'accéder facilement au livret d'accueil depuis leur smartphone et par demande de l'entreprise elle même qui me disais qu'un QRCode serias mieux pour eux car cela réduirait l'utilisation de leur imprimante et de leur consommation en papier.
