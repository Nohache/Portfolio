💻 Développeur WEB – Stage de 1ʳᵉ année

📅 16 Mai – 25 Juin 2025 · Familles Rurales, Bressuire

Objectif : Informatiser l'entreprise.

Principales réalisations :

  • Changement du site web de l'entreprise.
  • Création d'un livret d'accueil pour les nouveaux employés.
  • Assistance à l'entreprise dans l'utilisation des outils informatiques.
  • Mise en place de QRCode

Languages : HTML, CSS, JavaScript, Python.

Rendu changement site web:

  • Le site web à été fait sur WordPress, on m'a demandé de refaire certaines pages. Cette page a été totalement refaite par mes soins et d'après les avis de l'entreprise. Certaines pages ont été refaite mais qu'avec des changement mineures comme de la mise en forme, des liens qui ne mène nul part, ...

Rendu livret d'accueil:

  • Voici la page d'accueil du livret d'accueil que j'ai créé pour les nouveaux employés de l'entreprise. J'ai choisi un thème qui correspond à l'identité visuelle de l'entreprise.
  • Voici un exemple de page que l'on peut retrouver dans le livret d'accueil. Sur cette page j'ai rajouté un système d'effet parallaxe : c'est à dire que les éléments de l'arrière-plans se déplacent plus lentement que les éléments au premier plan lors du défilement de la page
  • Voici un exemple de menu. Ce sont des pages qui sont là pour segmenter le livret d'accueil en différentes parties.
  • Voici le code d'un élément que j'ai utilisé dans le livret d'accueil, c'est un loader. Un loader est une animation qui s'affiche pendant le chargement d'une page ou d'un élément. J'ai utilisé ce loader pour rendre l'expérience utilisateur plus agréable pendant le chargement du livret d'accueil.

Rendu QRCode:

  • Voici le code d'un QRCode que j'ai créé pour l'entreprise. Un QRCode est un code barre en 2D qui peut être scanné avec un smartphone pour accéder à une page web ou à une information. J'ai créé ce QRCode pour permettre aux employés d'accéder facilement au livret d'accueil depuis leur smartphone et par demande de l'entreprise elle même qui me disais qu'un QRCode serias mieux pour eux car cela réduirait l'utilisation de leur imprimante et de leur consommation en papier.
